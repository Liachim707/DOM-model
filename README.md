# DOM-model

## Описание проекта

DOM-model — это интерактивное веб-приложение с галереей случайных изображений. Проект демонстрирует работу с DOM (Document Object Model) с помощью JavaScript, а также использование HTML и CSS для создания и оформления интерфейса.

## Возможности приложения

- Просмотр случайных изображений в галерее.
- Обновление всех изображений без перезагрузки страницы.
- Добавление новых изображений в галерею.
- Удаление изображений из галереи.
- Защита от удаления последнего изображения: когда в галерее остаётся одна картинка, кнопка удаления становится неактивной.

## Как запустить проект

### В CodeSandbox

1. Откройте [CodeSandbox](https://codesandbox.io/).
2. Импортируйте репозиторий GitHub: `https://github.com/Liachim707/DOM-model`.
3. Дождитесь загрузки файлов проекта.
4. Откройте предпросмотр (Preview), чтобы увидеть приложение и проверить его работу.

### Локально на компьютере

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в терминале.
3. Установите зависимости командой:

   ```bash
   npm install
   ```

4. Запустите приложение:

   ```bash
   npm start
   ```

5. Откройте в браузере адрес, который покажет сервер в терминале.
