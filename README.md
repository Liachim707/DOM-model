# DOM-model

## Описание проекта

DOM-model — это интерактивное веб-приложение с галереей случайных изображений. Проект демонстрирует работу с DOM (Document Object Model) с помощью JavaScript, а также использование HTML и CSS для создания и оформления интерфейса.

## Возможности проекта

- Просмотр случайных изображений в галерее.
- Обновление всех изображений без перезагрузки страницы.
- Добавление новых изображений в галерею.
- Удаление изображений из галереи.
- Защита от удаления последнего изображения: когда в галерее остаётся одна картинка, кнопка удаления становится неактивной.
